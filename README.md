# LiliShop - Mini Système d’Information en Python + MySQL

Ce projet illustre un **mini Système d’Information (SI)** avec gestion des produits, ventes et utilisateurs, en utilisant **Python** pour la partie applicative et **MySQL** pour la base de données.

---

## 🏗️ Architecture du projet

Le projet couvre les 5 architectures classiques d’un SI :

- **Architecture fonctionnelle** : gestion des produits, ventes, utilisateurs.  
- **Architecture applicative** : modules Python (`main.py`, `produits.py`, `ventes.py`, `users.py`, `database.py`).  
- **Architecture technique** : MySQL pour la base de données + interface Python.  
- **Architecture des données** : tables SQL (`users`, `produits`, `ventes`).  
- **Architecture sécurité** : contrôle d’accès (`admin` / `employe`) et hashage des mots de passe (SHA-256).
